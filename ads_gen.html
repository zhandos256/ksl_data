KSL Ads Generator

Генерирует безопасный JSON для `data/ads.json` и remote `ksl_data/main/data/ads.json`. Лимиты совпадают с `src/ads.js` и `docs/ADS.md`.

Баннер включён
`enabled:false` скрывает баннер без удаления из JSON.
Используется только в полном `ads.json`.
Короткий badge сверху. Например: `Сервис`, `Партнёр`, `Реклама`.
Разрешены только `https://`, `http://`, `mailto:`.
Главная фраза. В UI максимум 2 строки, поэтому лучше писать коротко.
Описание видно под title. Важно: без длинной “простыни”, максимум 2 строки.
