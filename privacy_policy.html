Kaspi Seller Lens (Unofficial)

Политика конфиденциальности

Прозрачно описываем, какие данные нужны расширению для расчётов, отчётов и печати накладных, где они хранятся и кому не передаются.

Дата вступления в силу: 26 мая 2026 г.

1. О расширении

Kaspi Seller Lens (Unofficial) - независимое расширение Chrome для продавцов на Kaspi.kz. Оно не является официальным продуктом Kaspi.kz и не связано с Kaspi.kz.

Расширение работает на страницах https://kaspi.kz/*, чтобы по действию пользователя рассчитывать показатели товара, сохранять историю, создавать отчёты и объединять накладные для печати.

Коротко: данные функций обрабатываются на устройстве пользователя и хранятся локально в Chrome. Расширение не использует аналитику или трекинг и не продаёт пользовательские данные.

2. Какие данные обрабатываются

Данные со страниц Kaspi

Для пользовательских функций расширение может прочитать видимые на странице сведения:

  • название товара, изображение и URL изображений галереи;
  • категорию, отображаемую цену, отзывы/продажи и артикул товара;
  • URL текущей страницы товара;
  • на странице продавца: название магазина, Merchant ID и URL страницы.

Введённые пользователем данные

Расширение сохраняет параметры расчёта: цену закупа, доставку, упаковку, карго, комиссию категории, бонус за отзыв, рекламу, ИПН и профили категорий.

Настройки и история

Расширение сохраняет выбранные CSS-селекторы, язык, настройки авто-открытия, историю товаров с рассчитанными значениями, а также кэш конфигурации баннеров и время его обновления.

3. Для чего используются данные

Данные используются только для видимых пользователю функций: калькулятора юнит-экономики, карточки товара, профилей категорий, истории и сравнения товаров, копирования ссылок, Excel- и PNG-отчётов, скачивания фото товара, режима магазина и подготовки накладных к печати.

Расширение не использует содержимое страниц Kaspi для персонализированной, ретаргетинговой или основанной на интересах рекламы.

4. Файлы накладных

Пользователь может загрузить ZIP-архив с PDF-накладными Kaspi. Такие файлы могут содержать сведения о заказе или покупателе, например имя, адрес или телефон, если они присутствуют в самой накладной.

Архив и PDF обрабатываются локально в браузере только для создания объединённого PDF. Расширение не отправляет накладные разработчику или на внешний сервер.

5. Где и как долго хранятся данные

Селекторы, настройки, профили, история и кэш баннеров сохраняются в chrome.storage.local в профиле Chrome пользователя. Они остаются там до замены, очистки данных расширения или удаления расширения.

Разработчик не получает доступ к содержимому локального хранилища пользователя.

6. Внешние сетевые обращения

  • Конфигурация баннера. Расширение получает JSON-конфигурацию с raw.githubusercontent.com по HTTPS и кэширует её локально на срок до 6 часов. Запрос не содержит данные товара, историю, настройки расчёта или накладные.
  • Изображения товара. По команде пользователя для PNG-отчёта или скачивания фото расширение может загрузить изображения, уже указанные на странице Kaspi, с соответствующего ресурса/CDN Kaspi.
  • Ссылка баннера. Нажатие пользователем на баннер открывает указанную в нём внешнюю страницу; далее действует политика этого сайта.

Расширение не отправляет разработчику содержимое страниц Kaspi, параметры калькулятора, историю товаров или файлы накладных.

7. Экспорт и буфер обмена

  • Excel-, PNG-, ZIP- и PDF-файлы создаются только по действию пользователя и скачиваются на его устройство.
  • Ссылки товара, магазина или контактные данные поддержки копируются только после нажатия соответствующей кнопки.
  • Расширение не читает содержимое буфера обмена.

8. Разрешения Chrome

Расширение использует разрешения, необходимые для заявленных функций:

storage Локальное сохранение селекторов, расчётов, профилей, истории, настроек интерфейса и кэша баннеров.
https://kaspi.kz/* Показ панели на Kaspi и чтение видимых данных страницы для пользовательских функций расширения.
raw.githubusercontent.com Загрузка JSON-конфигурации баннера по защищённому HTTPS-соединению.

9. Передача, продажа и реклама

Kaspi Seller Lens (Unofficial) не продаёт пользовательские данные, не передаёт их рекламным платформам или брокерам данных и не позволяет разработчику или другим людям читать локально сохранённые данные пользователя.

Баннер является общей конфигурацией содержимого: он не выбирается на основании данных товара, истории или поведения пользователя в расширении. Внешние обращения ограничены случаями, описанными в разделе 6.

10. Chrome Web Store Limited Use

The use of information received from Google APIs and Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Доступ к содержимому страниц и хранилищу используется только для предоставления и улучшения пользовательских функций, описанных в этой политике и на странице расширения.

11. Управление данными и изменения политики

Пользователь может заменить сохранённые настройки через интерфейс расширения или удалить локальные данные, удалив расширение либо очистив его данные в Chrome.

При изменении функций или обработки данных политика будет обновлена. Актуальная версия публикуется по ссылке, указанной в Chrome Web Store.
