Политика конфиденциальности Kaspi Seller Lens (Unofficial)

Дата вступления в силу: 25 мая 2026 г.

Kaspi Seller Lens (Unofficial) - независимое расширение Chrome для продавцов на Kaspi.kz. Расширение не является официальным продуктом Kaspi.kz и не связано с Kaspi.kz.

Контакт по вопросам конфиденциальности: r.zhandos256@gmail.com

Kaspi Seller Lens (Unofficial) работает на страницах https://kaspi.kz/*, чтобы по команде пользователя показывать калькулятор, сохранять историю товаров, формировать выгрузки и объединять накладные. Данные этих функций обрабатываются на устройстве пользователя и сохраняются локально в браузере. Расширение не использует аналитику или трекинг, не продаёт пользовательские данные и не использует их для персонализированной рекламы.

Какие данные обрабатывает расширение

Данные со страницы Kaspi

Если пользователь настроил селекторы или открыл поддерживаемую страницу, расширение может прочитать видимые на странице данные:

  • название, изображение и URL изображений галереи товара;
  • категорию, отображаемую цену, отзывы/продажи и артикул товара;
  • URL текущей страницы товара;
  • на странице продавца: название магазина, Merchant ID и URL страницы.

Эти данные нужны только для расчётов, карточки товара, истории, переходов, копирования ссылки и пользовательских экспортов.

Данные, введённые пользователем

Расширение сохраняет параметры расчёта, включая цену закупа, доставку, упаковку, карго, комиссию категории, бонус за отзыв, рекламу и ИПН, а также настройки профилей категорий.

Настройки, история и кэш баннеров

Расширение сохраняет CSS-селекторы, язык и настройки авто-открытия, историю товаров с рассчитанными значениями, а также локальный кэш содержимого рекламных баннеров и время его обновления.

Файлы накладных

Пользователь может выбрать ZIP-архив с PDF-накладными. Архив и PDF обрабатываются локально в браузере для создания объединённого PDF. Kaspi Seller Lens (Unofficial) не отправляет эти файлы разработчику или на внешний сервер.

Где хранятся данные

Настройки, профили, история, селекторы и кэш баннеров хранятся локально через chrome.storage.local в профиле Chrome пользователя. Данные хранятся до их замены, очистки данных расширения в браузере или удаления расширения. Разработчик Kaspi Seller Lens (Unofficial) не получает доступа к содержимому локального хранилища.

Внешние сетевые обращения

  • Конфигурация рекламного баннера. Расширение получает JSON-конфигурацию с raw.githubusercontent.com и кэширует её локально на срок до 6 часов. Запрос не содержит данные товара, настройки, историю или файлы пользователя. GitHub может обрабатывать стандартные технические сведения запроса согласно собственной политике.
  • Изображения товара. Только когда пользователь запускает «Фото-отчёт» (PNG) или «Скачать фото товара», расширение может загрузить изображения, уже указанные на странице товара Kaspi, с соответствующего CDN/ресурса для формирования локального файла.
  • Переход по баннеру. При нажатии на баннер открывается указанная в нём внешняя ссылка. После перехода применяются правила соответствующего сайта.

Kaspi Seller Lens (Unofficial) не отправляет разработчику данные страницы Kaspi, историю, параметры калькулятора или загруженные пользователем накладные.

Экспорт, загрузки и буфер обмена

  • Excel-, PNG-, ZIP- и PDF-файлы формируются по действию пользователя и скачиваются через браузер на его устройство.
  • Копирование ссылок или контактных данных поддержки выполняется только после нажатия пользователем соответствующей кнопки.
  • Расширение не читает содержимое буфера обмена.

Передача, продажа и реклама

Kaspi Seller Lens (Unofficial) не продаёт пользовательские данные и не передаёт их рекламным платформам или брокерам данных; не использует такие данные для персонализированной, ретаргетинговой или основанной на интересах рекламы; не позволяет разработчику или другим людям читать локально сохранённые данные пользователя.

Единственные обращения к внешним сторонам описаны выше: GitHub получает запрос за общей конфигурацией баннера, ресурсы изображений Kaspi/CDN запрашиваются по выбранной пользователем функции экспорта или скачивания, а внешний сайт открывается только после клика по баннеру.

Рекламный баннер является общей конфигурацией содержимого и не выбирается на основании данных товара, истории или поведения пользователя в расширении.

Chrome Web Store Limited Use

The use of information received from Google APIs and Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Доступ к данным страницы и хранилищу используется только для предоставления описанных пользовательских функций Kaspi Seller Lens (Unofficial).

Изменения политики

При изменении функций расширения или способов обработки данных эта политика будет обновлена. Актуальная версия будет опубликована по URL, указанному на странице Kaspi Seller Lens (Unofficial) в Chrome Web Store.
